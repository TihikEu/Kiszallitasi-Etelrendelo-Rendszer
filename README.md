# Kiszallitasi-Etelrendelo-Rendszer
Trello link: https://trello.com/invite/b/6ab3dae333d98553c6927821/ATTI17cfb361476a4218b9808f588f13ab15E1A652AB/kiszallitasi-etelrendelo-rendszer

Technológiák: Bootstrap 5, Icons, Google Font.
<br>Reszponzivitás: Az asztali és mobil nézetnek is megfelelőnek kell lennie.
<br>Kinézet: A csatolt pillanatképek iránymutatók, de a felépítés és a grafika legyen hasonló.
<br>Validáció: Az adatok ellenőrzése, a hibaüzenetek Modal-ban vagy Toast-ban jelenjenek meg.
<br>JS osztályok és egységtesztek: Minimum 2 osztály szükséges. Az egyik csapattag írja az osztályt, a másik teszteli, majd fordítva. Ennek a tapasztalatait be kell mutatni a PPT-ben.
<br>Grafika: Alaposan kidolgozott grafika.
<br>PowerPoint: Be kell mutatni, ki mit csinált, a tesztelést, a felhasznált eszközöket és a tapasztalatokat.
<br>Eszközök: GitHub, Trello, Figma.
<br>AI használata: Megengedett, de maximum 50%-ban. Az AI használatát szigorúan jelezni kell a PPT-ben. Ennek elmulasztását elégtelennel díjazza a tanár.
